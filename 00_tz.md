# Техническое задание: Локальный AI-агент с модульной архитектурой

## Контекст
Разработай полноценную систему AI-агента для Android (Termux), которая:
1. Принимает текстовые запросы от пользователя (включая голосовой ввод с ошибками распознавания)
2. Определяет тип задачи через роутер
3. Использует локальную LLM (Qwen 2.5 0.5B) для формулировки намерений
4. Выполняет действия через модульные инструменты
5. Возвращает структурированные результаты

## Архитектура системы
### Компоненты:
1. **Главный диспетчер** (`main.py`): Принимает задачу, вызывает роутер, запускает инструмент, возвращает результат.
2. **Роутер задач** (`router.py`): Анализирует ключевые слова, определяет инструмент, возвращает название.
3. **База инструментов** (`tools/`): `search_web.py`, `reminder.py`, `file_reader.py`, `code_gen.py`. Реестр в `tools_registry.json`.
4. **Локальная LLM** (Qwen 2.5 0.5B через llama.cpp): ТОЛЬКО для формулировки поисковых запросов, извлечения сущностей, генерации коротких текстов. НЕ для сложной логики.

## Технические требования
1. **Обработка запросов**: Вход может содержать опечатки ("установитт питон") и лишние слова. Система должна извлекать суть.
2. **Интеграция с llama.cpp**: Путь: `/data/data/com.termux/files/home/models/qwen2.5-0.5b-instruct-q4_k_m.gguf`. Использовать `subprocess.Popen` с `communicate(timeout=30)` и `process.kill()`. Извлекать ответ между последним `>` и `[ Prompt:`.
3. **Инструмент: Поиск в интернете** (`search_web.py`): DuckDuckGo HTML. Полноценные HTTP-заголовки. Парсинг `<a class="result__snippet">` и `<a class="result__title">`. Возврат 4-5 результатов.
4. **Инструмент: Напоминания** (`reminder.py`): Замена "завтра" на конкретную дату ДО отправки в модель. Модель извлекает сущности в JSON. Создание через `termux-notification` или календарь.
5. **Инструмент: Чтение файлов** (`file_reader.py`): Чтение пути, суммаризация текста в 2-3 предложения моделью.
6. **Формат данных**: Все инструменты возвращают JSON.
   - Поиск: `{"query": "...", "results": ["...", "..."]}`
   - Напоминание: `{"person": "...", "action": "...", "deadline": "YYYY-MM-DDTHH:MM:SS"}`
